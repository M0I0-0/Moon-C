# Maneuvers bridge (`lib/maneuvers.js`)

Source: [`front-end/src/lib/maneuvers.js`](../../../front-end/src/lib/maneuvers.js). The maneuver logic and texts live in `Model3D/moonc/maniobras.js` ([model3d/maneuvers.md](../model3d/maneuvers.md)); this module only connects them to the app: files, environment mapping, cameras, when to open a guide and how to send its report.

## Re-exports and localized names

| Export | From Model3D |
|---|---|
| `MANIOBRAS`, `ENTORNOS`, `FUENTES`, `MANEUVERS_EN` (`EN`) | The definitions |
| `maneuverTitle(id, lang)` | `tituloManiobra`: "RCP (paro cardiaco)" / "CPR (cardiac arrest)" |
| `environmentName(key, lang)` | `datosEntorno(key, lang).nombre` |
| `sourceText(key, lang)` | `textoFuente`: the cited source of a step |

## Files

Vite serves the Model3D assets through `?url` imports, so the guide receives explicit URLs instead of building `base + name`:

```js
MANEUVER_FILES  = { 'maniqui_rcp.glb': …, 'maniqui_brazo.glb': …, 'maniqui_torso.glb': … }   // passed as `archivos`
MANEUVER_IMAGES = { 'metodo_pino.jpg': …, 'heimlich.jpg': … }                                // step illustrations
```

## Constants

| Constant | Value |
|---|---|
| `MANEUVER_LIST` | `['rcp', 'torniquete', 'atragantamiento']` (menu order; labels in `i18n.js`) |
| `ENV_TO_MANEUVER` | App environment → maneuver environment: `iss → iss`, `moon → luna`, `mars → marte`, `home → tierra`. The app always uses `home`, so guides start in `tierra`; the user can change it in the panel |
| `MANEUVER_CAMS` | Camera `[position, target]` per guide in Moon-C's model space (copied from `Model3D/moonc/moonc-escena.js`): CPR `[[1.2, 1.0, 4.2], [0.15, -0.4, 0.55]]`, tourniquet `[[0.9, 0.35, 2.3], [-0.12, -0.45, 0.5]]`, choking `[[-2.6, 0.4, 2.4], [0, -0.4, 0.45]]` |

## When a guide opens

There are four ways, from the most explicit to the most automatic:

1. **Menu → Guided maneuvers (3D).**
2. **By name in the chat** — `explicitManeuver(message)`: the message mentions the guide (accents ignored). The guide opens at once, without asking the backend.

   | Guide | Words |
   |---|---|
   | `rcp` | rcp, reanimación, reanimar, resucitación, masaje cardiaco, cpr, resuscitation, resuscitate |
   | `torniquete` | torniquete, tourniquet |
   | `atragantamiento` | atragant…, heimlich ("choking" is not here: in English the guide opens after the backend's emergency reply) |

3. **A button in the log** — `suggestedManeuver({ protocol, message })` after a reply: `fainting_unresponsive` → CPR, `bleeding` → tourniquet, `breathing_difficulty` with "atragant", "ahog", "choking", "se atoró" → choking. It never opens by itself.
4. **Automatically** — `autoOpenManeuver({ category, protocol, message })`, a pure function that opens a guide only for an **emergency** reply with unambiguous words:

   | Guide | Condition |
   |---|---|
   | CPR | Suggested CPR **and** the message says the person does not respond or breathe ("no responde", "no respira", "sin pulso", "inconsciente", "paro cardiaco", "unresponsive", "not breathing", "cardiac arrest"…) |
   | Tourniquet | Suggested tourniquet **and** a limb is named (arm, leg, hand, foot, thigh…) or the bleeding is heavy ("mucho", "a chorros", "no para", "won't stop", "spurting", "severe"…). A nose or gum bleed without a limb never opens it |
   | Choking | Same as the suggestion |

   Otherwise it returns `null` and the log keeps the button. `App` does not replace a guide that is already open. The panel then shows "Moon-C opened this guide because you described an emergency. If it is not what you need, close it (Esc)."

Opening a guide (any way) calls `POST /maneuvers/start` when the backend is online, which alerts the crew and the medical officer (except for an automatic opening from a crew account, where the chat already raised the alert).

## `replyIntro(reply, protocol)`

When a guide opens by itself, Moon-C speaks only the emergency sentence of the reply and lets the guide read the steps: the text before the protocol title, or the first sentence (at most 240 characters).

## `toReportSummary(pkg)`

Converts the guide's "Summary for Earth" (`controller.paqueteTierra()`) into the backend's `ManeuverSummary` for `POST /maneuvers/reports`:

| Model3D field | Backend field | Rule |
|---|---|---|
| `maniobra` | `title` | ≤ 200 characters, default "Maniobra" |
| `entorno` | `environment` | ≤ 100 |
| `retrasoComunicacion` | `comm_delay` | ≤ 100 |
| `evacuacion` | `evacuation` | ≤ 100 |
| `inicio` | `started_at` | ISO time or `null` |
| `duracionSeg` | `duration_s` | Whole, ≥ 0 |
| `compresiones`, `ciclos` | `compressions`, `cycles` | Whole, ≥ 0, or `null` |
| `torniquete` | `tourniquet_time` | ≤ 40 ("TQ 14:32") |
| `eventos[{hora, seg, evento}]` | `events[{at, elapsed_s, event}]` | Last 500, event text ≤ 200 |

Only data generated by the guide; never chat text.
